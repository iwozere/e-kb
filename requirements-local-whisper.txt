# Optional: local (on-device) Whisper transcription via faster-whisper.

# version ctranslate2 has published wheels for (Python 3.14 is not yet
# supported as of writing — see https://github.com/OpenNMT/CTranslate2).

# back to the OpenAI Whisper API automatically, with a warning in the logs).
